# ⚙️ `actions` — Pipeline Steps

The `actions` package turns every function of the library that takes **one main value and returns
one result** into an `Action` from [`simplibs-actions`](https://pypi.org/project/simplibs-actions/).
An action is the function with its options bound in advance: constructed once, then called with the
one value that changes — which is what makes steps chainable into a pipeline.

```python
from simplibs.file.actions import ReadJson
from simplibs.serialize.actions import Deserialize, DumpJsonFile

migrate = (
    ReadJson()                                      # path   -> data          (simplibs.file.actions)
    >> Deserialize(annotation=Config)               # data   -> Config
    >> upgrade                                      # Config -> Config        (any function is a step)
    >> DumpJsonFile(path="out/config.json", sort_keys=True)   # Config -> the written Path
)

migrate("old/config.json")            # -> Path('<cwd>/out/config.json')
await migrate.acall("old/config.json")   # the same, off the event loop
```

Actions are **not** exported from `simplibs.serialize` itself — they are a domain of their own,
imported through `simplibs.serialize.actions`, which defines `__all__`. Seven actions in four
groups: **convert**, **text**, **files** and **destinations**.

## How an action is built and called

Each action is generated by `create_action` from its function. One parameter is named as the
*main input* (`main_param`); **every other parameter** becomes a keyword-only *constructor option*.

```python
action = ToJson(indent=None, sort_keys=True)          # options
action({"b": 1, "a": 2})                              # main input
# -> '{"a": 2, "b": 1}'
```

* **Constructor options are validated** by the same annotations as the function's parameters — a
  wrong type or value is a `ValidationError` at construction (a list as `indent`, for example). A *missing
  required* option is a plain `TypeError` (`Deserialize()`, `DumpJsonFile()`).
* **The main input is validated** when the action is called.
* **Errors raised by the function surface unchanged** — an action adds no layer of its own
  (`SerializationError`, `DeserializationError`, `NotFoundError`, `AlreadyExistsError`, …).
* **The class docstring is the function's docstring**, and `_input_type` / `_output_type` expose
  the annotations for tooling.

## What flows and what is configuration

| Action           | Wraps                    | Main input (flows)   | Required option  | Returns                   |
|------------------|--------------------------|----------------------|------------------|---------------------------|
| `Serialize`      | [`serialize`](logic/README_SERIALIZE_SERIALIZER.md#serialize)       | `obj`                | —                | a JSON structure          |
| `Deserialize`    | [`deserialize`](logic/README_SERIALIZE_DESERIALIZER.md#deserialize)     | `data`               | `annotation`     | an object of `annotation` |
| `ToJson`         | [`to_json`](logic/README_SERIALIZE_JSON_IO.md#to_json)         | `obj`                | —                | `str`                     |
| `FromJson`       | [`from_json`](logic/README_SERIALIZE_JSON_IO.md#from_json)       | `json_str`           | `annotation`     | an object of `annotation` |
| `DumpJsonFile`   | [`dump_json_file`](logic/README_SERIALIZE_JSON_IO.md#dump_json_file)  | `obj`                | `path`           | `Path`                    |
| `LoadJsonFile`   | [`load_json_file`](logic/README_SERIALIZE_JSON_IO.md#load_json_file)  | `path`               | `annotation`     | an object of `annotation` |
| `DumpJsonFileTo` | [`dump_json_file`](logic/README_SERIALIZE_JSON_IO.md#dump_json_file)  | `path`               | `obj`            | `Path`                    |

## Content or path — which one flows?

A file writer needs two things: *what* to write and *where*. A pipeline step has room for only one
of them as its input, so the library offers **both**, as sibling actions over the same function —
exactly as `simplibs-file` does:

| The **object** flows — the path is an option | The **path** flows — the object is an option |
|----------------------------------------------|----------------------------------------------|
| `DumpJsonFile(path=...)`                     | `DumpJsonFileTo(obj=...)`                    |

Rule of thumb: a **single** target fed by a changing object is `DumpJsonFile`
(`... >> DumpJsonFile(path=target)`); the **same** object written to many targets is
`DumpJsonFileTo` (`ForEach(DumpJsonFileTo(obj=Settings()))`).

## One annotation per action

The annotation does not flow with the data, because a pipeline carries **one** value. So
`Deserialize`, `FromJson` and `LoadJsonFile` take it as a **required option**, and one action builds
one type. For a list of items, wrap it: `ForEach(Deserialize(annotation=Item))`; for a list of
files, `ForEach(LoadJsonFile(annotation=Config))`.

## What changes the disk

| Group           | Changes the disk?                                       |
|-----------------|---------------------------------------------------------|
| `convert/`      | No — a structure in memory.                             |
| `text/`         | No — a string in memory.                                |
| `files/`        | `LoadJsonFile` reads only; **`DumpJsonFile` writes**.   |
| `destinations/` | **Yes** — `DumpJsonFileTo` writes.                      |

Both writers return the **normalized `Path`** of what they produced, so the next step can carry on
with it. An object that cannot be converted fails **before** the disk is touched — see
[`dump_json_file`](logic/README_SERIALIZE_JSON_IO.md#dump_json_file).

## Composition

```python
step_a >> step_b          # run step_b on the result of step_a      (a flat sequence)
step_a & step_b           # run both on the same input              -> (result_a, result_b)
step_a | fallback_step    # run fallback_step if step_a raises
```

A `Rule` is a valid step on either side: `IsSerializable() >> ToJson()` verifies the input, passes
it on **unchanged** (a `guard`), or raises the rule's own failure card — see the
[rules](README_SERIALIZE_RULES.md). That is why `is_serializable` and `is_deserializable` have no
action of their own.

```python
send = IsSerializable() >> ToJson(indent=None) >> post_to_api
safe = (IsSerializable() >> ToJson()) | ToJson(default=repr)       # a fallback when the first fails
```

## Async

All seven actions are synchronous, so `await action.acall(data)` runs them in a worker thread
(`asyncio.to_thread`) — the right model for blocking file-system calls — and a whole pipeline can
be awaited the same way.

## What is not here

* **`is_serializable`, `is_deserializable`** — a `bool` is not a pipeline value; use the
  [`IsSerializable`](README_SERIALIZE_RULES.md#isserializable) and
  [`IsDeserializable`](README_SERIALIZE_RULES.md#isdeserializable) rules as gates.
* **`register_type`, `unregister_type`** — the set-up of the library, not a step of data flow.

# Convert

### `Serialize`

Wraps [`serialize`](logic/README_SERIALIZE_SERIALIZER.md#serialize) — the object flowing in becomes
a JSON-compatible structure, in the middle of a pipeline where a structure is needed.

**Constructor options:**

* `default` (*ToHandler | None*, default `None`): The fallback for an object nothing else can convert.
* `allow_nan` (*bool*, default `False`): If `True`, `nan` and `inf` pass through.

**Main input:** any supported object (`obj`). **Returns:** a JSON-compatible structure 
(`None`, `bool`, `int`, `float`, `str`, `list`, `dict`).

**Example usage:**

```python
Serialize()({"when": date(2024, 1, 2), "tags": {"b", "a"}})
# -> {"when": "2024-01-02", "tags": ["a", "b"]}

Serialize(default=repr)(object())                      # -> '<object object at 0x...>'

pipeline = LoadConfig() >> Serialize() >> send_to_api  # a structure in the middle
```

**Notes.** Errors surface unchanged: a `SerializationError` with the location of the bad value.

<details>
<summary>🔍 Under the hood</summary>

```python
Serialize = create_action(
    serialize,
    main_param="obj",
    class_name="Serialize",
)
```

</details>

### `Deserialize`

Wraps [`deserialize`](logic/README_SERIALIZE_DESERIALIZER.md#deserialize) — builds the configured
`annotation` from the data flowing in. `ReadJson() >> Deserialize(annotation=Config)`: the file's
content becomes a typed object with its rules checked.

**Constructor options:**

* `annotation` (*TargetType*, **required**): What to build — a class, `list[Point]`, `dict[str, int]`, …
* `strict` (*bool*, default `True`): Unknown keys are an error.

**Main input:** a structure (`data`). **Returns:** an object of `annotation`.

**Example usage:**

```python
Deserialize(annotation=Point)({"x": 1, "y": 2})                 # -> Point(x=1, y=2)
Deserialize(annotation=list[date])(["2024-01-02"])              # -> [date(2024, 1, 2)]
Deserialize(annotation=Point, strict=False)({"x": 1, "y": 2, "z": 3})   # -> Point(x=1, y=2)

items = ForEach(Deserialize(annotation=Item))                   # one annotation, many values
Deserialize()                                                   # -> raises: TypeError (annotation is required)
```

**Notes.** One annotation per action — the annotation does not flow with the data. A
`DeserializationError` names the location of the value that does not fit.

<details>
<summary>🔍 Under the hood</summary>

```python
Deserialize = create_action(
    deserialize,
    main_param="data",
    class_name="Deserialize",
)
```

</details>

# Text

### `ToJson`

Wraps [`to_json`](logic/README_SERIALIZE_JSON_IO.md#to_json) — writes the object flowing in as JSON
text: a compact body at the end of a pipeline, a log line, a message.

**Constructor options:**

* `indent` (*int | str | None*, default `2`): Indentation; `None` for compact one-line output.
* `ensure_ascii` (*bool*, default `False`): If `False`, non-ASCII text is written as it is.
* `sort_keys` (*bool*, default `False`): Sort object keys — reproducible output.
* `allow_nan` (*bool*, default `False`): If `False`, `NaN` and `Infinity` are an error.
* `default` (*ToHandler | None*, default `None`): The fallback for an object nothing else can convert.

**Main input:** any supported object (`obj`). **Returns:** `str` — without a trailing newline.

**Example usage:**

```python
ToJson(indent=None)({"name": "Čech", "n": [1, 2]})     # -> '{"name": "Čech", "n": [1, 2]}'
ToJson(indent=None, sort_keys=True)({"b": 1, "a": 2})  # -> '{"a": 2, "b": 1}'

body = build_message >> ToJson(indent=None)             # a request body at the end of a pipeline
```

<details>
<summary>🔍 Under the hood</summary>

```python
ToJson = create_action(
    to_json,
    main_param="obj",
    class_name="ToJson",
)
```

</details>

### `FromJson`

Wraps [`from_json`](logic/README_SERIALIZE_JSON_IO.md#from_json) — builds the configured
`annotation` from the JSON text flowing in: a request body becomes a typed object.

**Constructor options:**

* `annotation` (*TargetType*, **required**): What to build.
* `strict` (*bool*, default `True`): Unknown keys are an error.

**Main input:** JSON text or UTF-8 bytes (`json_str`). **Returns:** an object of `annotation`.

**Example usage:**

```python
FromJson(annotation=Point)('{"x": 1, "y": 2}')          # -> Point(x=1, y=2)
FromJson(annotation=list[int])(b"[1, 2, 3]")            # -> [1, 2, 3]

message = receive_body >> FromJson(annotation=Message)  # text in, typed object out
FromJson(annotation=Point)('{"x": 1,}')                 # -> raises: DESERIALIZE_INVALID_JSON (line, column)
```

<details>
<summary>🔍 Under the hood</summary>

```python
FromJson = create_action(
    from_json,
    main_param="json_str",
    class_name="FromJson",
)
```

</details>

# Files

### `DumpJsonFile`

Wraps [`dump_json_file`](logic/README_SERIALIZE_JSON_IO.md#dump_json_file) — writes the object
flowing in to the configured `path`: the end of a pipeline that produced an object. **Changes the
disk.**

**Constructor options:**

* `path` (*PathLike*, **required**): The target file. Its folder is created if missing.
* `indent` (*int | str | None*, default `2`): Indentation; `None` for compact output.
* `ensure_ascii` (*bool*, default `False`): If `False`, non-ASCII text is written as it is.
* `sort_keys` (*bool*, default `False`): Sort object keys — clean diffs.
* `allow_nan` (*bool*, default `False`): If `False`, `NaN` and `Infinity` are an error.
* `default` (*ToHandler | None*, default `None`): The fallback for an object nothing else can convert.
* `trailing_newline` (*bool*, default `True`): The file ends with a line ending.
* `encoding` (*EncodingName*, default `"utf-8"`), `newline` (*NewlineMode*, default `"\n"`), `overwrite` (*bool*, default `True`), `use_draft` (*bool*, default `True`), `sync` (*bool*, default `False`): As for [`write_json`](https://pypi.org/project/simplibs-file/).

**Main input:** any supported object (`obj`). **Returns:** the normalized `Path` of the target.

**Example usage:**

```python
DumpJsonFile(path="out/config.json")(config)                   # -> Path('<cwd>/out/config.json')
DumpJsonFile(path="out/config.json", sort_keys=True)(config)   # keys in alphabetical order
DumpJsonFile(path="out/config.json", overwrite=False)(config)  # -> raises: AlreadyExistsError, if it exists

pipeline = LoadJsonFile(annotation=Config) >> upgrade >> DumpJsonFile(path="out/config.json")
```

**Notes.** A value that cannot be converted fails with a `SerializationError` **before** the disk is
touched, so an existing file stays intact. Sibling: [`DumpJsonFileTo`](#dumpjsonfileto).

<details>
<summary>🔍 Under the hood</summary>

```python
DumpJsonFile = create_action(
    dump_json_file,
    main_param="obj",
    class_name="DumpJsonFile",
)
```

</details>

### `LoadJsonFile`

Wraps [`load_json_file`](logic/README_SERIALIZE_JSON_IO.md#load_json_file) — reads the file flowing
in and builds the configured `annotation`. Typically `ForEach(LoadJsonFile(annotation=Config))` over
a list of paths: each file becomes a typed object, with its rules checked.

**Constructor options:**

* `annotation` (*TargetType*, **required**): What to build.
* `strict` (*bool*, default `True`): Unknown keys are an error.
* `encoding` (*EncodingName*, default `"utf-8-sig"`): The text encoding; the default tolerates a BOM.
* `errors` (*EncodingErrors*, default `"strict"`): How to treat bytes the encoding cannot decode.

**Main input:** a path (`PathLike`). **Returns:** an object of `annotation`.

**Example usage:**

```python
LoadJsonFile(annotation=Config)("config.json")                    # -> Config(port=8080, ...)

configs = CollectFiles(include_filter=HasSuffix(".json")) >> ForEach(LoadJsonFile(annotation=Config))
# -> [Config(...), Config(...)]    (a list of paths in, a list of typed objects out)

LoadJsonFile(annotation=Config)("missing.json")                   # -> raises: NotFoundError
```

**Notes.** A file that is not valid JSON fails in `read_json` (a `ConversionError`); JSON that does
not fit the type fails in `deserialize` with the location of the bad value. Both are a
`ConversionError`. The alternative is `ReadJson() >> Deserialize(annotation=...)`, which does the
same in two visible steps and lets you put another step between them.

<details>
<summary>🔍 Under the hood</summary>

```python
LoadJsonFile = create_action(
    load_json_file,
    main_param="path",
    class_name="LoadJsonFile",
)
```

</details>

# Destinations

### `DumpJsonFileTo`

Wraps [`dump_json_file`](logic/README_SERIALIZE_JSON_IO.md#dump_json_file) — writes the configured
`obj` to the path flowing in: the same default settings written to every path of a list.
**Changes the disk.**

**Constructor options:**

* `obj` (*Any*, **required**): The object to write.
* All the other options of [`DumpJsonFile`](#dumpjsonfile) — `indent`, `ensure_ascii`, `sort_keys`, `allow_nan`, `default`, `trailing_newline`, `encoding`, `newline`, `overwrite`, `use_draft`, `sync`.

**Main input:** a path (`path`). **Returns:** the normalized `Path` of the target.

**Example usage:**

```python
DumpJsonFileTo(obj=Settings())("a/settings.json")                 # -> Path('<cwd>/a/settings.json')

ForEach(DumpJsonFileTo(obj=Settings(), sort_keys=True))(["a/s.json", "b/s.json"])
# -> [Path('<cwd>/a/s.json'), Path('<cwd>/b/s.json')]
```

**Notes.** The object is converted for every path; if it cannot be converted, the first path fails
and no file is touched. Sibling of [`DumpJsonFile`](#dumpjsonfile).

<details>
<summary>🔍 Under the hood</summary>

```python
DumpJsonFileTo = create_action(
    dump_json_file,
    main_param="path",
    class_name="DumpJsonFileTo",
)
```

</details>
